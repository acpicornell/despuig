The published site at <https://despuig.corpusbalear.org>, built with Astro as a
static site. Moved here from the top-level README.

## `web/` — the public website (Astro, static)

The published site: town pages (1785 census + cartela text + clean vignette + locator
map), a filterable/sortable table of the ~2,515 curated toponyms, an interactive **Mapa**
(geographic layer), a deep-zoom viewer of the engraving (**El gravat**), and statistics ("the 1785 map" vs "our
reading process"). Catalan UI; cartela texts kept in
their original period spelling. It is **self-contained**: it only reads the
JSON under `web/src/data/` (generated by `npm run data`, which CI runs before every
build, plus the hand-written `pobles-editorial.json`), never the pipeline internals.

```bash
cd web
npm install
npm run data        # build src/data/*.json from the per-sheet pipeline output
npm run vinetes     # town vignettes  (needs data/jpg/, local-only)
npm run hero        # homepage hero crop
npm run map         # DZI tiles for the engraving deep-zoom on /gravat (slow; only when the master changes)
npm run sheets      # per-quadrant DZIs for the toponym-detail viewer on /toponims (slow; only when the master changes)
npm run dev         # http://localhost:4330
npm run build       # → web/dist  (prebuild runs data + vinetes + hero)
```

## Deploy

Deploy = **Cloudflare Workers (Static Assets)**, automatic on push to the default branch
(see [`.github/workflows/deploy.yml`](../.github/workflows/deploy.yml)); manually with `npm run deploy` (= build +
`wrangler deploy`, config in `web/wrangler.toml`). The generated deploy assets
(`web/public/{map,sheets,vinetes,hero}`) are versioned, so a clean checkout reproduces
the whole site. Third-party libraries and fonts are self-hosted under
`web/public/vendor/` (see [`web/public/vendor/README.md`](../web/public/vendor/README.md)),
so the site loads no runtime CDN and can enforce the strict CSP in
`web/public/_headers`.
